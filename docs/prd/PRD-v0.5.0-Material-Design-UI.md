# PRD：MetaAgent v0.5.0 — Material Design 风格化 UI 升级

| 文档信息 | 内容         |

| 作者   | 产品经理智能体    |
| 日期   | 2026-09-04 |

> **v0.4.0 → v0.5.0 变更说明**：v0.4.0 实现了工具执行框架和界面简洁化，但整体 UI 风格仍偏"技术 demo"感，视觉语言不统一，交互体验不够流畅。v0.5.0 的核心目标是**全面引入 Material Design 设计语言**，让产品从"能用"进化到"好用、好看"。重点改造智能体卡片（极简 + 整卡点击交互）和聊天页面（功能入口清晰、排版简洁美观）。

***

## 1. 背景与目标

### 1.1 问题分析

| #  | 问题        | 用户痛点                              | 影响范围  |
| -- | --------- | --------------------------------- | ----- |
| P1 | UI 风格不统一  | Element Plus 默认主题缺乏品牌识别，各页面视觉语言零散 | 产品观感  |
| P2 | 智能体卡片过于臃肿 | 卡片上堆了 4-5 个按钮，信息密度过高，操作路径模糊       | 核心列表页 |
| P3 | 聊天页功能入口分散 | 记忆、邮件、通讯录等入口藏在小按钮里，用户不知道去哪里找      | 核心交互页 |
| P4 | 卡片交互不直觉   | 用户想和智能体对话，需要先找到"💬 对话"按钮，不能直接点卡片  | 交互效率  |

### 1.2 产品目标

| 维度       | 目标                                          |
| -------- | ------------------------------------------- |
| **视觉目标** | 全站采用 Material Design 3 设计语言，打造统一、现代、精致的视觉体验 |
| **交互目标** | 智能体卡片整卡可点击，一跳直达聊天页；聊天页功能入口清晰可见              |
| **体验目标** | 核心操作路径从"2-3 步"缩短到"1 步"，减少用户认知负担             |
| **技术目标** | 基于 CSS 变量覆盖 Element Plus 主题，不引入额外 UI 框架     |

### 1.3 成功指标

| 类型  | 指标         | 目标值                      |
| --- | ---------- | ------------------------ |
| 体验1 | 聊天入口操作步数   | 从 2 步降到 1 步（点击卡片直接进聊天）   |
| 体验2 | 聊天页功能入口可见性 | 记忆/邮件/通讯录/设置 4 个入口首屏全部可见 |
| 性能1 | 前端包体积增量    | ≤ 20KB（CSS 变量覆盖，无新依赖）    |
| 质量1 | 页面视觉一致性    | 全站色彩、圆角、阴影、字体统一          |

### 1.4 非目标（本期不做）

| 不做                              | 原因                                |
| ------------------------------- | --------------------------------- |
| 引入完整 Material UI 组件库（如 Vuetify） | 现有 Element Plus 已足够，用 CSS 变量覆盖更轻量 |
| 深色模式                            | 先把浅色 MD 风格做好，深色模式后续版本             |
| 响应式移动端适配                        | 本期聚焦桌面端，移动端留后                     |
| 智能体卡片拖拽排序                       | 功能复杂，非本期核心                        |
| 设置页面的完整功能                       | 本期只做入口按钮，设置页内容后续补充                |

## 2. 用户与场景

### 2.1 核心使用场景

| #  | 场景        | 描述                             |
| -- | --------- | ------------------------------ |
| S1 | 选择智能体进入对话 | 用户在智能体列表页，想要和某个智能体聊天，直接点击卡片进入  |
| S2 | 聊天中访问功能   | 用户在聊天中，想查看智能体的记忆、邮箱、通讯录，一眼找到入口 |
| S3 | 浏览整体界面    | 用户打开任何页面，都感受到统一、现代、舒适的视觉风格     |

### 2.2 核心交互流程

```
场景 S1：点击智能体卡片进入聊天
  用户 → 浏览智能体列表 → 点击任一卡片任意位置 → 进入该智能体聊天页
  
场景 S2：聊天页功能入口访问
  用户 → 在聊天页顶部看到：[邮件] [记忆] [通讯录] [设置]
       → 点击任意图标按钮 → 进入对应功能页
       → 功能页提供返回按钮 → 返回聊天
```

### F1 全局 Material Design 主题

**功能描述**：定义一套完整的 MD3 Design Token 系统，通过 CSS 变量覆盖 Element Plus 默认主题。

**MD3 颜色系统**：

| Token                       | 色值        | 用途             |
| --------------------------- | --------- | -------------- |
| `--md-primary`              | `#6750A4` | 主色调（按钮、链接、选中态） |
| `--md-on-primary`           | `#FFFFFF` | 主色上的文字         |
| `--md-primary-container`    | `#EADDFF` | 主色容器（卡片背景）     |
| `--md-on-primary-container` | `#21005D` | 主色容器上的文字       |
| `--md-secondary`            | `#625B71` | 次要色            |
| `--md-tertiary`             | `#7D5260` | 强调色            |
| `--md-surface`              | `#FEF7FF` | 表面色（页面背景）      |
| `--md-surface-variant`      | `#E7E0EC` | 表面变体（卡片背景）     |
| `--md-on-surface`           | `#1D1B20` | 表面上的文字         |
| `--md-on-surface-variant`   | `#49454F` | 表面变体上的文字       |
| `--md-outline`              | `#79747E` | 边框/分隔线         |
| `--md-error`                | `#B3261E` | 错误色            |
| `--md-success`              | `#386A20` | 成功色            |
| `--md-warning`              | `#B36500` | 警告色            |

**MD3 形状系统**：

| Token             | 值        | 用途        |
| ----------------- | -------- | --------- |
| `--md-shape-xs`   | `4px`    | 小标签、徽章    |
| `--md-shape-sm`   | `8px`    | 输入框、小按钮   |
| `--md-shape-md`   | `12px`   | 普通按钮、卡片   |
| `--md-shape-lg`   | `16px`   | 大卡片、对话框   |
| `--md-shape-xl`   | `28px`   | 底部抽屉、大容器  |
| `--md-shape-full` | `9999px` | 圆形头像、图标按钮 |

**MD3 阴影系统**：

| Token              | 值                                                              | 用途       |
| ------------------ | -------------------------------------------------------------- | -------- |
| `--md-elevation-0` | `none`                                                         | 平面元素     |
| `--md-elevation-1` | `0 1px 2px 0 rgba(0,0,0,0.30), 0 1px 3px 1px rgba(0,0,0,0.15)` | 卡片默认     |
| `--md-elevation-2` | `0 1px 2px 0 rgba(0,0,0,0.30), 0 2px 6px 2px rgba(0,0,0,0.15)` | 卡片 hover |
| `--md-elevation-3` | `0 1px 3px 0 rgba(0,0,0,0.30), 0 4px 8px 3px rgba(0,0,0,0.15)` | 对话框      |

### F2 智能体卡片精简重构

**功能描述**：删除卡片上的所有操作按钮（对话、通讯录、信箱、设置下拉），只保留核心信息。

**卡片内容结构（从上到下）**：

```
┌─────────────────────────────────────┐
│  ┌─────┐                            │
│  │ 🤖  │  Agent Name                │
│  │ Avatar │  公开/私有 · 状态徽章    │
│  └─────┘                            │
│                                     │
│  friendly · curious · professional  │  ← persona_tags
│                                     │
│                          📮 3       │  ← 未读邮件徽章（仅当有未读时）
└─────────────────────────────────────┘
     ↑ 整卡可点击，hover 有 MD elevation-2 反馈
```

**删除的元素**：

* ❌ "💬 对话" 按钮

* ❌ "📒 通讯录" 按钮

* ❌ "📮 信箱" 按钮

* ❌ "⚙️" 设置下拉菜单（含切换公开/私有、禁用/启用、删除）

**设置功能迁移**：进入聊天页后通过聊天页的设置入口访问。

### F3 智能体卡片整卡点击交互

**功能描述**：卡片任意位置可点击，点击后路由跳转到该智能体的聊天页 `/chat/:agentId`。

**交互反馈**：

| 状态    | 视觉反馈                                         |
| ----- | -------------------------------------------- |
| 默认    | `elevation-1` 阴影                             |
| Hover | `elevation-2` 阴影 + `scale(1.01)` 轻微放大 + 主色光晕 |
| Press | `elevation-1` 阴影 + `scale(0.99)` 轻微缩小        |
| 键盘聚焦  | 2px 主色 outline 环                             |

**业务规则**：

* R1：卡片点击不包括"未读邮件徽章"的点击——徽章点击跳转到 mailbox 页

* R2：卡片禁用态（`status === 'disabled'`）时点击无效，显示禁用光标

* R3：点击不触发冒泡到父元素

## 4. 非功能需求

### 4.1 性能

| 指标       | 要求                |
| -------- | ----------------- |
| CSS 体积增量 | ≤ 15KB（gzip）      |
| 页面渲染性能   | 所有页面 Paint ≤ 50ms |
| 无新增外部请求  | 全部 CSS 内联或构建时注入   |

### 4.2 兼容性

| 类型  | 要求                               |
| --- | -------------------------------- |
| 浏览器 | Chrome / Edge / Safari 最新 2 个版本  |
| 分辨率 | 最小 1280×720                      |
| 字体  | 系统字体栈（优先 Roboto，回退 Noto Sans SC） |

### 4.3 可访问性

| 项     | 要求                            |
| ----- | ----------------------------- |
| 颜色对比度 | 正文 ≥ 4.5:1，大文字 ≥ 3:1（WCAG AA） |
| 键盘导航  | 所有可交互元素支持 Tab 聚焦              |
| 点击热区  | 图标按钮 ≥ 48×48px                |

### 4.4 向后兼容

| 项      | 要求               |
| ------ | ---------------- |
| API 接口 | 无任何变更，纯前端改造      |
| 数据结构   | 无任何变更            |
| 路由     | 路由结构保持不变，仅导航方式变化 |
