# meta-world

meta-world 项目仓库，包含设计文档、源代码、测试用例及相关脚本。

## 目录结构

```
meta-world/
├── docs/        # 设计文档
├── src/         # 源代码
├── testcase/    # 测试用例
├── buglist/     # 测试问题单
├── scripts/     # 脚本
└── README.md    # 项目说明
```

## 目录说明

| 目录 | 用途 |
|------|------|
| `docs/` | 存放项目设计文档，包括架构设计、接口设计、技术方案等 |
| `src/` | 存放项目源代码 |
| `testcase/` | 存放测试用例 |
| `buglist/` | 存放测试过程中发现的问题单 |
| `scripts/` | 存放构建、部署、开发辅助等脚本 |
