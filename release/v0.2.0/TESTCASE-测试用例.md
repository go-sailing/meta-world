| JWT 签名密钥 | server/.env 的 JWT\_SECRET（默认 `change-me-in-production-xxxxxxxxxxxxx`） |

### 前置准备

```bash
# 1. 安装依赖并构建
cd /workspace && npm install && npm run build

# 2. 启动后端（开发模式）
npm run dev:server     # http://localhost:3000

# 3. 另起终端启动前端
npm run dev:web        # http://localhost:5173

# 4. 健康检查
curl http://localhost:3000/health
# → {"status":"ok"}
```

## 1. 用户注册（F1）

### TC-F1-01 正常注册

| 项         | 内容                                                                                            |
| --------- | --------------------------------------------------------------------------------------------- |
| **步骤**    | `POST /api/auth/register` `{"email":"alice@demo.com","password":"Alice1234"}`                 |
| **预期**    | 返回 201，`{"user_id":"<UUID>","email":"alice@demo.com"}`                                        |
| **DB 验证** | `SELECT * FROM user WHERE email='alice@demo.com'` 存在，password\_hash 非明文，bcrypt hash 长度约 60 字符 |
| **前端验证**  | 注册页提交后自动跳转 `/login` 或提示"注册成功"                                                                 |

### TC-F1-02 重复邮箱

| 项      | 内容                                                   |
| ------ | ---------------------------------------------------- |
| **前置** | 已执行 TC-F1-01                                         |
| **步骤** | 再次用 `alice@demo.com` 注册                              |
| **预期** | 返回 409，`{"error":"EMAIL_EXISTS","message":"该邮箱已注册"}` |

### TC-F1-03 邮箱格式不合法

| 项      | 内容                                            |
| ------ | --------------------------------------------- |
| **步骤** | 邮箱传 `"notanemail"` / `"@demo.com"` / `"foo@"` |
| **预期** | 返回 400，`{"error":"INVALID_EMAIL"}`            |

### TC-F1-04 密码不含字母

| 项      | 内容                                    |
| ------ | ------------------------------------- |
| **步骤** | 密码传 `"12345678"`（8 位但纯数字）             |
| **预期** | 返回 400，`{"error":"INVALID_PASSWORD"}` |

### TC-F1-05 密码不含数字

| 项      | 内容                                    |
| ------ | ------------------------------------- |
| **步骤** | 密码传 `"abcdefgh"`（8 位但纯字母）             |
| **预期** | 返回 400，`{"error":"INVALID_PASSWORD"}` |

### TC-F1-06 注册接口限流

| 项      | 内容                              |
| ------ | ------------------------------- |
| **步骤** | 同一 IP 连续注册 6 次不同邮箱              |
| **预期** | 第 6 次返回 429 `Too Many Requests` |

## 2. 用户登录（F2）

### TC-F2-01 正常登录

| 项          | 内容                                                                         | <br />                                                               |
| ---------- | -------------------------------------------------------------------------- | :------------------------------------------------------------------- |
| **前置**     | 已注册 alice                                                                  | <br />                                                               |
| **步骤**     | `POST /api/auth/login` `{"email":"alice@demo.com","password":"Alice1234"}` | <br />                                                               |
| **预期**     | 返回 200，`{"token":"<JWT>","user_id":"<UUID>","email":"alice@demo.com"}`     | <br />                                                               |
| **JWT 验证** | \`echo "<token>"                                                           | base64 -d`能看到`{"sub":"\<user\_id>","email":"<alice@demo.com>",...}\` |
| **DB 验证**  | user 表 last\_login\_at 被更新                                                 | <br />                                                               |

### TC-F2-02 密码错误

| 项       | 内容                                       |
| ------- | ---------------------------------------- |
| **步骤**  | 用正确邮箱但错误密码登录                             |
| **预期**  | 返回 401，`{"error":"INVALID_CREDENTIALS"}` |
| **关键点** | 错误信息不区分"邮箱不存在"和"密码错误"（防枚举）               |

### TC-F2-03 邮箱不存在

| 项      | 内容                                              |
| ------ | ----------------------------------------------- |
| **步骤** | 用未注册邮箱登录                                        |
| **预期** | 返回 401，`{"error":"INVALID_CREDENTIALS"}`（同密码错误） |

### TC-F2-04 Token 过期

| 项        | 内容                                                  |
| -------- | --------------------------------------------------- |
| **前置**   | 登录拿到 token                                          |
| **步骤**   | 修改 JWT\_SECRET 重启服务，或手动篡改 token 尾部                  |
| **预期**   | 带篡改 token 访问 `/api/agents` → 返回 401 `TOKEN_EXPIRED` |
| **前端验证** | 收到 401 后自动跳转 `/login?redirect=原路径`                  |

### TC-F2-05 登录接口限流

| 项      | 内容              |
| ------ | --------------- |
| **步骤** | 同一 IP 连续登录 11 次 |
| **预期** | 第 11 次返回 429    |

### TC-F2-06 /auth/me 查询当前用户

| 项      | 内容                                              |
| ------ | ----------------------------------------------- |
| **前置** | 已登录拿到 token                                     |
| **步骤** | `GET /api/auth/me` + Authorization header       |
| **预期** | `{"user_id":"<UUID>","email":"alice@demo.com"}` |

## 4. 智能体创建（归属用户）（F4）

### TC-F4-01 正常创建（公开）

| 项         | 内容                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------ |
| **前置**    | Alice 已登录，token=$TOKEN\_A                                                                        |
| **步骤**    | `POST /api/agents` `{"name":"天气助手","persona_tags":["friendly","professional"],"is_public":true}` |
| **预期**    | 返回 201，agent 含 owner\_user\_id=Alice 的 user\_id，is\_public=true，status='active'                  |
| **DB 验证** | agent 表 owner\_user\_id 字段正确写入，persona\_tags 为 JSON 字符串                                          |

### TC-F4-02 正常创建（私有）

| 项      | 内容                                                                 |
| ------ | ------------------------------------------------------------------ |
| **步骤** | `POST /api/agents` `{"name":"私人笔记","persona_tags":["analytical"]}` |
| **预期** | is\_public 默认 false                                                |

### TC-F4-03 同用户下重名

| 项      | 内容                                        |
| ------ | ----------------------------------------- |
| **前置** | Alice 已有一个叫"天气助手"的智能体                     |
| **步骤** | 再创建一个叫"天气助手"的                             |
| **预期** | 返回 409，`{"error":"AGENT_NAME_DUPLICATE"}` |

### TC-F4-04 不同用户可以重名

| 项      | 内容                   |
| ------ | -------------------- |
| **前置** | Alice 有"天气助手"，Bob 没有 |
| **步骤** | Bob 创建名为"天气助手"的公开智能体 |
| **预期** | 返回 201（跨用户重名允许）      |

### TC-F4-05 超过每用户 10 个上限

| 项      | 内容                                              |
| ------ | ----------------------------------------------- |
| **步骤** | 连续创建 11 个智能体                                    |
| **预期** | 第 11 次返回 400，`{"error":"AGENT_LIMIT_EXCEEDED"}` |

## 7. 智能体禁用/删除（F7）

| ------ | ----------------------------------------------------------- |
| **步骤** | `PUT /api/agents/:id/disable`                               |

## 15. 数据库数据检查清单

### 每次测试后执行以下 SQL 验证

```sql
-- ======== v0.2.0 新增 ========
-- 用户数量
SELECT COUNT(*) AS user_count FROM user;

-- 用户邮箱列表
SELECT user_id, email, last_login_at FROM user;

-- 每个用户的智能体数
SELECT owner_user_id, COUNT(*) AS agent_count FROM agent GROUP BY owner_user_id;

-- 公开 vs 私有
SELECT is_public, COUNT(*) FROM agent GROUP BY is_public;

-- 已禁用 vs active
SELECT status, COUNT(*) FROM agent GROUP BY status;

-- 通讯录分布
SELECT COUNT(*) FROM address_book;
SELECT owner_agent_id, COUNT(*) FROM address_book GROUP BY owner_agent_id;

-- 双向好友（A→B 且 B→A）
SELECT COUNT(*) FROM address_book ab1
INNER JOIN address_book ab2
  ON ab1.owner_agent_id = ab2.target_agent_id
 AND ab1.target_agent_id = ab2.owner_agent_id;

-- ======== v0.1.0 原有 ========
SELECT layer, COUNT(*) FROM memory_item GROUP BY layer;
SELECT status, COUNT(*) FROM letter GROUP BY status;
SELECT COUNT(*) FROM chat_message;
```
